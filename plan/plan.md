# NeonWallet (tg-crypto-gate): запуск существующего проекта

Platform: Web app

## Что это
Кастодиальный крипто-кошелёк в Telegram (TON, USDT TON, USDT TRC20) с платёжным шлюзом для мерчантов и веб-админкой.
Код уже написан и лежит на GitHub: https://github.com/TIMUrka4457/tg-crypto-gate. Задача — перенести его как есть и запустить, новых функций не добавлять.

## Для кого
- Пользователи Telegram: хранят крипту, переводят друг другу, создают чеки и оплачивают счета через мини-приложение.
- Мерчанты: принимают оплату по API-ключу и получают вебхуки.
- Владелец и сотрудники платформы: управляют всем через веб-админку (/admin).

## Основные функции и как с ними работают (уже есть в коде)
- Мини-приложение Telegram (/app): баланс, пополнение, вывод, переводы по @username, чеки с условиями, счета, рефералы, кабинет мерчанта.
- Telegram-бот: команда /start, ссылки на чеки и счета, уведомления, рассылки.
- Веб-админка (/admin): вход по паролю + код на email, роли (owner/admin/support), пользователи, депозиты, выводы, мерчанты, настройки, аудит, статистика.
- Фоновые процессы: сканирование депозитов в TON/TRON, сбор средств на горячий кошелёк (sweep), отправка выводов, вебхуки мерчантам.
- Интерфейс на русском, тёмная неоновая тема по design_guidelines.json.

## Assumptions
- Ключи и секреты передаются агенту-сборщику через защищённую форму, в план не записываются: токен Telegram-бота, ключ TonAPI, ключ TronGrid; остальные секреты (подпись сессий, мастер-ключ, пароль владельца) генерируются при запуске.
- Пароль владельца генерируется и передаётся пользователю, код входа (OTP) приходит через встроенную почтовую рассылку Emergent.
- Адреса контрактов USDT — официальные мейнет-адреса (USDT на TON и USDT TRC20 Tether).
- Мастер-ключ хранится в настройках сервера рядом с API (встроенный режим подписи); пользователя предупреждают, что его нужно сохранить в надёжном месте, иначе средства на адресах будут потеряны.
- Для денежных операций нужна база с поддержкой транзакций; сборщик настраивает её, без этого денежные операции не запустятся.
- Лимиты, комиссии и пороги — значения по умолчанию из кода; их можно поменять в админке.
- Ссылка на мини-приложение — адрес превью/продакшена приложения на Emergent с путём /app.
